How to Manage macOS Spaces and Move Windows Between Desktops

macOS Spaces are separate desktops shown in Mission Control. SpaceControl adds shortcuts for creating and selecting Spaces and moving a selected window between adjacent Spaces while Mission Control is open.

Set up

Download SpaceControl from GitHub Releases, launch it, and grant Accessibility access in System Settings → Privacy & Security → Accessibility. Open Mission Control to use these controls. The defaults can be changed through the menu-bar icon → Settings… (or ⌘,); if the icon is hidden, launch SpaceControl again to open settings.

Create or select a Space

Press ⌘N to create a Space on the display under the pointer. Press ⌘1 through ⌘9, or ⌘0 for Space 10, to switch on that display and close Mission Control.

Move a window

Select a window in Mission Control, then press ⌘← or ⌘→ to move it to the previous or next Space. The project also implements ⌘⌃← and ⌘⌃→ to move and follow, but the website’s feature demo is currently withheld because this behavior is not yet reliable.

Compatibility

Windows that belong to multiple Spaces cannot be moved this way, and there must be an adjacent Space in the chosen direction. Moving windows uses a private SkyLight operation rather than a public macOS API. It may break in future macOS versions.

SpaceControl targets macOS 14 or later and has been tested on macOS 27. Its reliance on undocumented Mission Control details and private APIs means other versions may not work, and future updates can break functionality.
