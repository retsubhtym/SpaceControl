How to Manage and Close Windows in macOS Mission Control

SpaceControl adds a close button to each Mission Control window thumbnail and keyboard commands for the selected window. The selected window is the one Mission Control highlights under the pointer.

Set up and close a window

Download SpaceControl from GitHub Releases, launch it, and grant Accessibility access in System Settings → Privacy & Security → Accessibility. Open Mission Control to use these controls. The defaults can be changed through the menu-bar icon → Settings… (or ⌘,); if the icon is hidden, launch SpaceControl again to open settings.

  1. Open Mission Control and point at a window, or select one using the arrow keys or h j k l.
  2. Click its × button or press ⌘W to close it.

Other window and app actions

Press ⌘M to minimize the selected window, ⌘H to hide its app, or ⌘Q to quit its app. Apps can still ask to save changes. Space invokes Mission Control’s normal preview.

Requirements and limits

Accessibility permission is needed to identify and act on windows. Actions depend on the target app’s accessibility support.

SpaceControl targets macOS 14 or later and has been tested on macOS 27. Its reliance on undocumented Mission Control details and private APIs means other versions may not work, and future updates can break functionality.
