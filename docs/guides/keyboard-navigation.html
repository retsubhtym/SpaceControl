How to Navigate macOS Mission Control with Keyboard Shortcuts

SpaceControl adds keyboard selection to macOS Mission Control. Its arrow and h, j, k, l shortcuts move the pointer between window thumbnails so Mission Control’s own hover highlight follows the selection.

Set up SpaceControl

Download SpaceControl from GitHub Releases, launch it, and grant Accessibility access in System Settings → Privacy & Security → Accessibility. Open Mission Control to use these controls. The defaults can be changed through the menu-bar icon → Settings… (or ⌘,); if the icon is hidden, launch SpaceControl again to open settings.

Navigate windows

  1. Open Mission Control and use the arrow keys or h j k l to move between windows.
  2. Press Return to open the selected window. Press Space to use Mission Control’s normal preview; SpaceControl hides its close buttons during preview.
  3. Use ⌘W to close the selected window or ⌘M to minimize it.

Compatibility

SpaceControl targets macOS 14 or later and has been tested on macOS 27. Its reliance on undocumented Mission Control details and private APIs means other versions may not work, and future updates can break functionality.
