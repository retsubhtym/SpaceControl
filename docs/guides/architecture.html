SpaceControl Architecture - Extending macOS Mission Control

SpaceControl is a macOS menu-bar application. It monitors Mission Control, draws close-button overlays, and routes configured keyboard shortcuts to window and Spaces operations.

Mission Control and windows

MissionControlMonitor detects the Dock’s mc placeholder and reads the WindowManager accessibility tree on macOS 27. MissionControlController refreshes while Mission Control is open and positions overlays. WindowResolver maps thumbnail window IDs to application windows using the private _AXUIElementGetWindow function, then uses Accessibility actions to close or minimize them.

Keyboard and Spaces

KeyboardInterceptor uses a Core Graphics event tap and handles configured keys while Mission Control is open. Spaces.swift uses private SkyLight functions and SLSBridgedMoveWindowsToManagedSpaceOperation to work with Spaces and move windows.

Permissions and compatibility

The app requests Accessibility permission to read and operate on windows and handle keys. Public Accessibility and Core Graphics APIs are used alongside private functions and undocumented UI structure; these implementation details are not stable Apple API contracts.

SpaceControl targets macOS 14 or later and has been tested on macOS 27. Its reliance on undocumented Mission Control details and private APIs means other versions may not work, and future updates can break functionality.
